# Farm Valley Prototype

A small top-down 2D farming prototype built in **Godot 4.7** while learning GDScript,
tilemaps and Godot's scene system.

**Status: paused.** The movement, world and farming basics work; the selling/buying
economy was never built. Kept public as a learning artefact.

## What works

- Top-down player movement with facing direction and idle/walk animations
- Scene transitions between the outdoor map and the house interior (door areas)
- Tilling: only ground tiles flagged `farmable` in the tileset can be tilled
- Planting: seeds go only on tilled soil, one crop per cell
- Growth: a timer advances each planted crop through five growth stages

## The map generator (`tools/mapgen`)

The map, the tileset resource and the scene files are **generated by Python**, not
hand-painted in the editor:

```bash
cd tools/mapgen
python3 render.py preview.png 2   # PNG preview of the map, no Godot needed
python3 emit.py                   # (re)write the Godot .tres/.tscn/.gd files
```

It handles 8-neighbour autotiling, per-tile metadata (multi-cell sizes, y-sort
pivots, collision), and works around a gap in the tileset art where the water tiles
have no concave corners. See `tools/mapgen/README.md` for details.

## Running it

The third-party art is **not included** in this repository (see below). To run the
project, download the *Tiny Wonder Farm (Free)* pack and place it in
`Assets/Tiny Wonder Farm Free/`, then open the project in Godot 4.7 or later.
